Password changes and staff account creation require at least 15 characters,
including a lowercase letter, uppercase letter, digit, and symbol. Supabase
Auth must be configured with the same password rules and secure password
changes enabled. Password changes also require a sign-in within the previous
24 hours; sign out and back in if the recent-sign-in check is not met.

See [Shiprocket shipping setup](./docs/shiprocket.md) for parcel configuration and server environment requirements.
